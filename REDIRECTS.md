# Redirect map

**Canonical host: `https://petrspecian.com`** (no hyphen, apex, not www). Every destination
below is relative to it. `petr-specian.com` and `www.petrspecian.com` are legacy hosts that 301
to the canonical one (verified 2026-09-22).

Every URL that currently exists on either Google Sites, mapped to its destination.
Blanket redirects to the homepage would throw away the inbound links that already
exist, so each path is mapped individually.

## How to implement

**petr-specian.com: done (2026-09-19).** The domain is on Cloudflare DNS and 301s every
path in the table above to `petrspecian.com`. Verified with curl.

**institutional-transformation.ai: Cloudflare redirect rules** (both domains on Cloudflare
DNS since 2026-09-18). One rule per row of the table, 301 not 302, apex and `www` both.
Nothing is hosted on the .ai domain afterwards; it is a forwarding shell kept registered
to the 2027-09-16 renewal (see `../rg-relocation-checklist.md`, Step 6).

Historical note: the original plan (meta-refresh HTML stubs generated by
`scripts/make_redirects.py`, or Namecheap URL records) was superseded by the Cloudflare
move. The script is kept for reference only.
